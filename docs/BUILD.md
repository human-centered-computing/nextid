# Build and verification plan

- Source lock: NextOpenSource commit 857048365d9a5265f43c10c0f1611409c00233ee, exact subtree 6f439a9bda71c39bf725150cea5d50f149e423f6, Keycloak 26.8.2. The source acquisition script verifies the Git commit and tree before exporting it; no personal Core repository or floating branch is used.
- Source build uses the upstream-documented Maven server distribution command, then packages the resulting tarball into a local Core image. Product image applies the NextID themes and builds the PostgreSQL configuration. JDK 21 build / JDK 21 runtime and PostgreSQL 16 are initial candidates. Pin container base image digests and verify compatibility before publication; these tags are not immutable.
- This is a local-only pilot (loopback HTTP, synthetic realm, no external audit endpoint). Production requires TLS, approved hostname and proxy configuration, secret management, credential rotation, backup/restore, access review and deployment approval.
- Verify build reproducibility, distribution/license notices, theme compatibility (login/account/admin), locale switches, login/logout, revoked sessions, access denial, SQL persistence and rollback with synthetic accounts. NextSecurity records independent evidence; no tests were run for this scaffold.
- The optional event-listener integration is outside the initial distribution pending compatibility and privacy review. The approved main-branch workflow builds and smoke-checks the product before publishing versioned and latest images under `ghcr.io/human-centered-computing/nextid`. No live deployment is automated. Check package visibility and distribution permissions after publication.
- Reference: [upstream build documentation](https://github.com/human-centered-computing/nextopensource/blob/857048365d9a5265f43c10c0f1611409c00233ee/Core/NextID-Core/source/docs/building.md) and [NextRoadmap](https://github.com/human-centered-computing/nextroadmap/tree/main/NextID).
