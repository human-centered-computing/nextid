# NextID

> حالة الترجمة: مسودة بمساعدة الذكاء الاصطناعي، بانتظار مراجعة لغوية بشرية.

[English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [العربية](README.ar.md)

NextID هو منتج إدارة الهوية والوصول المركزي في NextLife. يوفر أساساً مشتركاً لهويات الأشخاص ومكونات البرمجيات المصرح بها، لتسجيل الدخول بأمان في التطبيقات المتكاملة دون حساب مستقل لكل تطبيق.

## ماذا يقدم NextID؟

| الإمكانية | الغرض |
|---|---|
| الهوية والمصادقة | التحقق من الهوية وإدارة دورة المصادقة. |
| تسجيل الدخول الموحد | دخول مشترك للتطبيقات المتكاملة. |
| الحسابات والجلسات | إدارة دورة الحساب والجلسات والخروج واستعادة بيانات الاعتماد. |
| الأدوار والمجموعات | تطبيق تعيينات NextRole المعتمدة؛ تفرض التطبيقات ضوابط الوصول الخاصة بها. |
| التوطين وإمكانية الوصول | سمات NextID للدخول والحساب والإدارة والبريد بالإنجليزية والتركية؛ يبقى التحقق من الشاشات وإمكانية الوصول شرطاً للقبول. |
| الفصل المؤسسي | إعدادات مستقلة لكل مؤسسة مع إعادة استخدام صورة المنتج. |

الهدف تقليل عبء تسجيل الدخول وإدارة الحسابات مع حماية الهوية والخصوصية وحقوق الوصول. ليس NextID جهة اعتماد سياسات الأدوار المؤسسية أو مخزناً للإعدادات الخاصة.

## المعمارية والمسؤوليات

| المكون | المسؤولية |
|---|---|
| [NextID-Core](https://github.com/human-centered-computing/nextopensource/tree/main/Core/NextID-Core) | المصدر المشترك وإمكانات الهوية الأساسية |
| NextID | حزم المنتج وخدمة الهوية وتجربة الحساب والتوطين وصورة النشر |

## المكونات

- `nextid-core`: خدمة الهوية والجلسات والتفويض المبنية من NextID-Core.
- `nextid-db`: قاعدة PostgreSQL.
- `themes/nextid`: سمات الواجهات والترجمات.

## التشغيل المحلي

بعد نشر الصورة يستخدم التوزيع الصورة التالية:

```text
ghcr.io/human-centered-computing/nextid:${NEXTID_CORE_IMAGE_TAG:-latest}
```

```bash
cp .env.example .env
# Set unique passwords in .env before starting.
docker compose up -d
```

الاختبار المعزول على http://localhost:8080. نطاق الهوية التجريبي لا يتضمن مستخدمين أو عملاء حقيقيين أو أسرار المؤسسات.

## إعدادات المؤسسات

تُدار في مستودع [NextConfig](https://github.com/human-centered-computing/nextconfig) الخاص وفق مجلدات المؤسسات والوحدات. يعرّف NextRole الأدوار والمجموعات ويطبق NextID التعيينات المعتمدة. لا إعدادات مؤسسية في مستودع المنتج العام.

## البناء والتوزيع

يثبت `core.lock` مراجعة المصدر. البناء المحلي من المصدر:

```bash
bash scripts/fetch-core.sh
bash scripts/build-local.sh
NEXTID_IMAGE=nextid NEXTID_CORE_IMAGE_TAG=26.8.2-local docker compose up -d
```

تبني GitHub Actions الصورة وتختبرها؛ تنشر عمليات البناء الناجحة المعتمدة للفرع الرئيسي في سجل الحاويات للمؤسسة. الوسوم لا تُنشأ إلا بعد نجاح التشغيل. راجع [ملاحظات البناء والنشر](docs/BUILD.md).

## الحالة

أساس منتج عام. نجح بناء الإصدارات المرشحة واختبار قاعدة البيانات ونطاق الهوية الاصطناعي. يجب التحقق منفصلاً من النشر والشاشات والأمن المستقل والمنفعة البشرية. لا ادعاء بنشر إنتاجي. تُحفظ إشعارات المصدر في [NOTICE](NOTICE)، ويجب تأكيد ترخيص الإضافات الأصلية قبل منح حقوق إعادة التوزيع.
