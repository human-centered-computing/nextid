# Realm configuration / Realm yapılandırması

Place Harran-specific, reviewed, non-sensitive NextID realm and client configuration here. No live realm export is included. Realm identity, allowed redirect domains, authentication requirements, identity providers and federation must be agreed with the institution; credentials and personal data are supplied securely at runtime.

Harran'a özgü onaylı ve hassas olmayan realm ve istemci yapılandırmaları burada tutulur. Gerçek realm dışa aktarımı eklenmemiştir. Kuruma ait kimlik sağlayıcıları, yönlendirme adresleri ve kimlik doğrulama politikaları kurumla doğrulanır; gizli bilgiler ve kişisel veriler güvenli biçimde çalışma anında sağlanır.
