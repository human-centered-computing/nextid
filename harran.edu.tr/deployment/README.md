# Deployment / Dağıtım

Harran-specific Docker Compose overrides, hostname, reverse proxy, TLS and database connectivity configuration belong here. Use the organization's NextID image; do not build an institution-specific image containing private data. Store only reviewed non-sensitive examples in this public repository. Provide secrets via an approved secret manager or protected runtime environment. A live deployment is not authorized by this folder.

Harran'a özel Docker Compose ayarları, alan adı, ters vekil, TLS ve veritabanı bağlantı yapılandırmaları burada tutulur. Organizasyonun NextID imajı kullanılır; kurumsal özel veriler imaja dahil edilmez. Herkese açık depoda yalnızca incelenmiş hassas olmayan örnekler bulunur. Gerçek dağıtım henüz yapılmamıştır.
